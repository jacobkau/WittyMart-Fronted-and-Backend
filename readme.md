# 🛒 WittyMart - E-Commerce System

## About
A functional e-commerce web application built with PHP HTML, CSS, and JavaScript. Features include product browsing, shopping cart, user authentication, and responsive design.

## Tech Stack
- PHP
- HTML5, CSS3, JavaScript (ES6)
- Bootstrap 5, Font Awesome
- RENDER for deployment

## Features
- 🛍️ Product catalog
- 🛒 Shopping cart
- 📱 Fully responsive
- 🔐 User login/register
- 💳 Checkout system - ON DEVELOPMENT
